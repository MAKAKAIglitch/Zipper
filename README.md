## 📄 Описание

**Zipper** — графическое приложение для Windows, которое управляет системной утилитой `compact.exe`. Оно сжимает папки с играми и программами без изменения содержимого файлов: Windows прозрачно сжимает их на диске, а приложения продолжают обращаться к ним как обычно. Результат зависит от типа файлов и выбранного алгоритма.

### 🔥 Основные фишки:
*   ✅ **GUI-интерфейс:** выбор папки через окно Проводника или перетаскиванием в окно.
*   ✅ **Русский и English:** переключение языка прямо в окне; выбор сохраняется.
*   ✅ **Контроль нагрузки:** число потоков, нагрузка, приоритет CPU и диска, включая пресеты «Тихо», «Баланс» и «Максимум».
*   ✅ **Анализ перед запуском:** показывает объём и число файлов, подходящих для обработки.
*   ✅ **Умная раскраска:** 
    *   🟢 **Зеленый:** Успешно сжато.
    *   🔴 **Красный:** Ошибка (файл занят системой).
*   ✅ **Non-Stop режим:** Скрипт не вылетает и не останавливается на ошибках.
*   ✅ **LZX Алгоритм:** Максимальное сжатие для современных игр.

## 📊 Сравнение режимов

| Режим | Сжатие | Нагрузка CPU | Для чего подходит |
| :--- | :---: | :---: | :--- |
| **XPRESS 4K** | Слабое | ⭐ | Очень слабые ПК |
| **XPRESS 8K** | Среднее | ⭐⭐ | Офисные программы, документы |
| **XPRESS 16K** | Сильное | ⭐⭐⭐ | Архивы, старый софт |
| **LZX (ULTRA)** | **Максимальное** | ⭐⭐⭐⭐ | **Игры (AAA), тяжелые программы** |

## 🛠 Установка

1. Перейдите в раздел **[Releases](../../releases)** и скачайте `Zipper.exe`.
2. Запустите его и подтвердите запрос UAC, если он появится.
3. Установка не требуется. Исходный вариант можно запускать из репозитория через `Zipper.ps1` или `Zipper.bat`.

## ⚙ Инструкция

1. Запустите `Zipper.exe` и выберите язык в правом верхнем углу.
2. Укажите папку с игрой или программой — можно перетащить её в окно.
3. Выберите алгоритм. **LZX** обычно подходит для больших игр, но требует больше времени и ресурсов.
4. При необходимости настройте потоки, лимит нагрузки и приоритеты. Эти параметры можно менять во время работы.
5. Нажмите **Анализ**, чтобы оценить объём, или **Сжать**, чтобы начать обработку. Для снятия сжатия нажмите **Снять сжатие**.

> **Примечание:** Если вы видите красные строчки `ERR` или `LOCK` — не пугайтесь. Это значит, что файл (например, лог или конфиг) сейчас используется Windows. Скрипт просто пропустит его и сожмет остальные файлы.

## 🇬🇧 English Short Description

**Zipper** is a Windows GUI for the built-in `compact.exe` utility. It can compress game and application folders using XPRESS or LZX while keeping files accessible to Windows and applications.

**Features:**
*   **Bilingual UI:** Switch between Russian and English; the choice is saved.
*   **Folder Selection:** Browse for a folder or drag it into the window.
*   **Resource Controls:** Configure CPU threads, workload throttling, and CPU/disk priorities.
*   **Live Progress:** Track throughput, elapsed time, errors, and disk-space changes.
*   **Fail-Safe:** Skips inaccessible files and continues processing.
